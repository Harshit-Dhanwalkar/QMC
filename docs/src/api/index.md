# API Reference

> Generated by `tools/gen_api.py` from the public headers. Do not edit.

QMC has **115 modules** and **790 public functions**. Three ways to find what you need:

1. **This reference**: every module below lists its types, constants and functions with the comment from the header, plus the example and test that show it in use.
2. **In code**: `#include <qmc/qmc.h>`, then `qmc_help(stdout, NULL);` for an overview, `qmc_help(stdout, "tight_binding");` for one module, or `qmc_help(stdout, "chern");` to search. `qmc_module_find()`, `qmc_module_search()` and `qmc_module_at()` give the same catalog as data.
3. **In a shell**: `qmc-help <module | category | keyword>` (installed by `make install`).

Most functions carry a module prefix (`tb_`, `qaoa_`, `json_`, ...). See [Using QMC as a Library](../setup/library.md) for installing and linking.
