QMC Playground - Kerr cat states

A quantum state of light has no sharp position and momentum, so it is drawn as a quasi-probability cloud, the Wigner function W(x, p): its marginals are the true distributions of x and p, but W itself is allowed to go negative, which is the signature of a non-classical state. A coherent state is a Gaussian blob. A Kerr medium adds a phase proportional to n(n−1), so the blob smears around its ring and at χt = π/2 becomes a Schrödinger cat: two blobs and interference fringes between them that dip below zero. Everything is computed live by the QMC library (ps_wigner).

photon-number distribution |cn|²: the Kerr phase never changes it
HKerr = χ n(n−1), so the state at time t is ∑ cn e−iχt n(n−1)|n⟩; the phase is even in n, so everything revives exactly at χt = π, and at χt = π/2 a coherent state is exactly (e−iπ/4|iα⟩ + eiπ/4|−iα⟩)/√2. The Wigner function is W(x,p) = (1/π) ∫ ψ*(x+y) ψ(x−y) e2ipy dy with ℏ = m = ω = 1. The negative volume is (∫|W|−1)/2: zero for any Gaussian state and positive for everything else. Source: physics/phase_space.c, wrapper wasm/qmc_wigner.c; the closed forms, marginals and the Kerr cat identity are checked in tests/test_phase_space.c.
