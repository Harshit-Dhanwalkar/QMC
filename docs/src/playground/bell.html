QMC Playground - Bell test

Alice and Bob each measure one spin of an entangled pair along an angle they choose. If the outcomes were fixed in advance by a hidden variable, the CHSH combination S = E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′) could never exceed 2. For a singlet the correlation is E = −V cos(a−b) and S reaches 2√2 ≈ 2.83. Drag the four angles and the noise: the correlations come from the two-qubit density matrix (bell_correlation), and the grey curve is the best local model I could write down, a hidden angle with each side outputting the sign of the projection.

CHSH value (local bound 2, quantum bound 2√2)

State: ρ = V|ψ−⟩⟨ψ−| + (1−V) I/4, detectors A(θ) = cosθ σz + sinθ σx. The violation needs V > 1/√2 ≈ 0.707. The local model here reaches exactly 2 at the best settings, and no deterministic strategy can do better (the code enumerates all 16). Simulated runs draw random outcome pairs with the exact quantum probabilities, so the estimate scatters around the true S with an error that shrinks as 1/√n. Real experiments also have to close detection and locality loopholes, which this toy does not model.
